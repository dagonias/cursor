# Controle tributário — Fator R / Simples Nacional

Planilha: [`controle-fator-r-impostos.xlsx`](./controle-fator-r-impostos.xlsx)

## Abas

1. **Leia-me** — como usar
2. **Parâmetros** — alíquotas, CLT, dependentes, cenários de pró-labore
3. **Notas** — nomes das empresas (editáveis) + valor da NF mês a mês
4. **Simulação** — Fator R (12 meses), Anexo III/V, DAS, INSS, IRRF, lucro isento e líquido familiar em 3 cenários
5. **Comparativo** — consolidado anual e impacto aproximado no IRPF
6. **Composição DAS** — rateio estimado (IRPJ, CSLL, PIS, COFINS, INSS, ISS)

Campos amarelos são editáveis. Ao mudar o valor da nota, a simulação recalcula o Fator R e o pró-labore sugerido (cenário C2).

Estimativa para planejamento — não substitui o PGDAS-D / contador.
