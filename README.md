## O que a planilha faz

1. **Parametros** — alíquotas, CLT, dependentes, cenários de pró-labore  
2. **Notas** — nomes das empresas (editáveis) + valor da NF mês a mês  
3. **Simulacao** — Fator R (12 meses), Anexo III/V, DAS, INSS, IRRF, lucro isento e líquido familiar  
4. **Comparativo** — consolidado anual  
5. **Composicao-DAS** — rateio estimado (Brasília-DF)

Campos amarelos = editáveis. Ao mudar o valor da nota, o Fator R e o pró-labore sugerido (C2) recalculam.

Estimativa para planejamento — não substitui o PGDAS-D / contador.
